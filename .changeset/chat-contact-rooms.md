Add contact rooms to Chat Extension v2. `chat.setRoomContact` (method 29) gives a room of the chat product its contact: the account, the username and where the conversation stands (`Invite`, `Outgoing`, `Incoming`, `Established`, `Blocked`, `PeerLeft`). A host that lists `contact_rooms` draws such a room as its own person-to-person chat, with the input of its native chat for the contact state; the core backs the feature only for the chat product. The user's answers reach the product as the user actions `AcceptRequest`, `DeclineRequest`, `Block`, `Unblock` and `Leave`, and the message origin `"contact"` is the contact. `ChatMessage` gains `request`, the welcome message of a chat request, and `ChatMessageBody` gains `Event` (request accepted, contact added, left chat, unavailable, unsupported), `Call` (a call record the host draws as its call bubble) and `Payment` (a transfer bubble). `ChatFeedUpdate::Replaced` draws a message again in its place without marking it edited. `chat.onEditHistory` (method 30) answers the earlier texts of a message for the host's edit history, and `chat.onSearchQuery` (method 27) the messages of a room that match what the user typed, newest first, for the host's search. `ChatMessage` gains `replyPreview`, the origin and body of the message it replies to, so the host quotes it without loading it; `ChatMediaMeta` gains `durationMs` for a video; `ChatReactionSummary` gains `unseen`, a reaction of the contact the user has not seen; and `ChatReactionDetail` gains `timestamp`. `ChatRoomPreview` carries `timestamp`, `badge`, `lastMessage`, `lastReaction` (with `removed` when the newest event removed a reaction) and `unseenReactions`, the number of the contact's reactions the user has not seen, from which the host makes its own preview line and badge. The user action `NewMessage` carries an optional `messageId` the host chose and an optional `timestamp`, when the user wrote it, and `CallRequested` an optional `callId`: the product sends the message, or the call and the message that records it, under that id and the message with that time, so the host shows them at once and follows them. Native hosts implement `NativeChatCallbacks.set_room_contact` and ask `NativeProductExecution.chat_edit_history` and `chat_search_query`.
