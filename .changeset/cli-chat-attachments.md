The `truapi-host dev` chat page sends photos, videos and files and lists `inline_attachments` and
`preimage_attachments`: up to 1 MiB a file travels inline, above it the core stages it as a preimage paid from the
product's own Bulletin allowance in a room that declares `preimage_attachments`, and the page refuses a file above
8 MiB.
