Funding for the host's screens: a crypto `FundingQuoteAsk` names its `network`, Worker manifest crypto routes declare `networks`, and candidates carry the `limits` quote refusals showed. `funding_progress` reports `retrying` and an outbound session's `payout`, which the provider reports after release with the new `FundingUpdate.Payout`. `FundingFailure.Refunded` ends an inbound payment the provider returned. A `FundingProviderEntry` marked `bundled` is a provider the host ships itself: the core goes by the host's manifest and never reads dotNS for it.
